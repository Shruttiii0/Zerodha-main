# Zerodha Clone

A full-stack Zerodha Clone built using React (frontend) and Node.js/Express with MongoDB (backend). This application simulates core functionalities of Zerodha, such as user authentication, live stock market data display (mock or via API), watchlist, and order placement.

---

## 🚀 Features

- User Authentication (Sign Up, Login)
- Live Stock Data Display (via mock or third-party API)
- Search and Add Stocks to Watchlist
- Place Buy/Sell Orders (mock implementation)
- Dashboard with Portfolio Summary
- Responsive UI with React

---

## 🛠 Tech Stack

### Frontend:
- React
- Redux Toolkit (for state management)
- React Router
- Axios

### Backend:
- Node.js
- Express
- MongoDB (Mongoose)
- JWT Authentication
- bcrypt for password hashing
